# Feng · 0→1 采购落地包（30 天版）

> 配套文件：《Feng-外贸采购分身-完整提示词-v1.0.md》场景六的展开版
> 前提：一个人、一台电脑、一个共享表格。不需要买系统，不需要招人。

---

## 一、先把"跑通"定义清楚（不定标准，就会永远在准备）

一单跑通 = 同时满足以下 5 条。少一条都不算：

1. 客户从询盘到收货，全程只经过你一人决策（没有第二个"我以为他处理了"）
2. 8 个节点里，至少 6 个有文件留痕
3. 中间出过至少 1 个问题，并被书面解决（**没有出问题的单不算跑通，因为没验证过你的兜底能力**）
4. 成本、费用、净利三个数对得上，误差 < 3%
5. 事后能写出 3 条改进

**这 5 条的作用**：防止你把第一单做成"侥幸成功"。侥幸成功的单，第二单会翻车。

---

## 二、第一单该接什么样的单（选单标准）

0→1 最常见的死法不是能力不够，是**第一单选了一个不该接的单**，然后被拖死。

### 该接（五条都满足）

| 条件 | 标准 | 为什么 |
|---|---|---|
| 金额 | 货值 3–10 万人民币 | 亏得起，赔得起 |
| SKU 数 | ≤ 3 个 | 一个 SKU 出问题还能救，五个同时出问题就崩 |
| 品类 | 你至少能看懂材质和工艺 | 看不懂就没法验货，没法判断工厂在骗你 |
| 客户 | 有明确规格书 / 图稿 / 样品 | 不用你教育他，省掉三轮来回 |
| 付款 | 能接受 30% 定金 + 出货前付清 | 不压你的钱 |

### 现在不能接（任一条命中就推掉或转介绍）

- 客户说不清要什么（"你先给我报个价看看"）
- 要 DDP 到门 + 账期 60 天（压资金 + 清关风险双重）
- 要"最低价"且明确说在比 5 家
- SKU 超过 5 个，每个都要打样
- 涉及认证（CE/FCC/FDA）而你没做过
- 客户是你完全不认识的中间商，且不愿意视频
- 需要开模且模具费客户不愿付

> 推掉单不丢人，第一单翻车才丢人。翻一次，你要用三个月恢复信心。

---

## 三、开跑前必须准备好的三样"兜底"

这三样不是软件，是你出问题时的救命绳。**没准备好就别开跑。**

**1. 一份自己的合同模板**
不要用工厂的合同（工厂模板一定偏向工厂）。至少要包含：规格附件、变更须书面批准、验货标准与 AQL、交期与延期罚则、质量责任与赔付上限、争议解决方式。
【需核实：正式使用前请律师过一遍，重点看"质量异议期"和"赔付上限"两条】

**2. 一个第三方验货渠道**
第一单必须用第三方验，不管金额多小。作用是：给你一份"不站在任何一方"的报告，客户信这个，工厂也怕这个。
【需核实：当地 SGS/BV/TÜV/Intertek 报价与排期，或本地独立验货员，费用通常按人天计】

**3. 一笔能兜住一单亏损的现金**
金额 = 单笔货值 × 20%。这笔钱不许动，它存在的意义是让你在出事时能立刻说"我赔"，而不是"我们商量一下"。
**"我赔"这两个字，是你这个生意最贵的资产。**

## 四、8 个节点的最小可行版

| # | 节点 | 你要做的动作 | 交付物（文件名） | 时限 | 一句话验收 |
|---|---|---|---|---|---|
| 1 | 需求确认 | 按 12 项澄清清单问全，回填确认单让客户书面确认 | `RQ-客户代号-001 需求确认单.docx` | 首响 2h / 确认 24h | 客户回了一句"对，就这些" |
| 2 | 寻源比价 | 找 3–5 家，用同一张对比表填（价格/交期/MOQ/资质/风险） | `SRC-客户代号-001 比价表.xlsx` | 3–5 天 | 表里每一行你都能说出"为什么这家排第几" |
| 3 | 正式报价 | 用统一成本表算，18 个字段填满，出带版本号的报价单 | `Q-20261117-客户代号-001-v1.pdf` | 48h | "包含/不包含"栏写满了 |
| 4 | 打样封样 | 规格书 → 申请单 → 首件确认 → 收样检验 → 客户签样 → 封样三份 → 拍照 | `SP-工厂代号-20261120-01 样品确认书.pdf` | 7–15 天 | 三份封样上都贴了标签，8 张照片齐了 |
| 5 | 下单 | PO 六项齐全（规格/数量/价格/交期/付款/验货标准）+ 定金水单 | `PO-客户代号-001.pdf` | 1 天 | 工厂盖了章，定金到了 |
| 6 | 跟单 | 每周固定一天发周报，附车间照片 | `PR-客户代号-001-W1.docx` | 每周 | 客户没有主动问过"到哪了" |
| 7 | 验货 | 按 AQL 抽检，出报告 + 放行单 | `INS-客户代号-001.pdf` | 出货前 5 天 | 有放行单才允许装柜 |
| 8 | 交付与客诉 | 出货通知 + 到港提醒 + 24h 客诉受理承诺 | `DLV-客户代号-001.xlsx` | 到港后 30 天 | 客户说"下次还找你" |

> 命名规则统一：`类型-对象-序号-版本`。这一条看着傻，但三个月后你能在三秒内找到任何一份文件。**这就是"离职不断档"的物理基础。**

## 五、30 天日程（按天，可打印）

### 第 1 周：把地基铺好（不接单）

| 天 | 做什么 | 产出 |
|---|---|---|
| D1 | 建共享表格（腾讯文档/飞书），建 6 个页签：询盘台账 / 报价台账 / 供应商库 / 样品台账 / 客诉台账 / 利润台账 | 一个链接 |
| D2 | 定报价成本表：货价 / 包装 / 内陆运费 / 报关 / 验货 / 损耗 / 资金成本 / 汇率缓冲 2% / 售后准备金 3–5% | 1 张 Excel，9 行 |
| D3 | 定询盘分级标准 + 首响模板（中英各一）；做一张"敏感品类合规预审清单" | 模板 3 份 |
| D4 | 建"需求确认单"（12 项）；建"报价单"（18 字段） | 模板 2 份 |
| D5 | 建"供应商档案"（15 字段）+ 评分卡（6 维权重）+ 准入红线清单 | 模板 3 份 |
| D6 | 建"样品确认书"（10 项）+ 封样标签 + 拍照清单（8 张）+ 验货报告模板 | 模板 4 份 |
| D7 | 建 PI 模板；按《采购合同十大条款》起草自己的合同模板；找验货渠道问价拿 2 个报价 | PI + 合同 + 报价 |

**第 1 周不接单是为了第 2 周不返工。** 这一周做完，你手上应该有 12 份模板 + 1 张合规清单。这就是你未来所有 SOP 的骨架。

### 第 2 周：用真单跑前 3 段（需求 → 寻源 → 报价）

| 天 | 做什么 | 检查点 |
|---|---|---|
| D8 | 发一条"开始接单"的消息给所有潜在客户/朋友（附一页流程说明） | 有没有人回 |
| D9–D10 | 接 3 个询盘，全部走分级 + 首响 + 需求确认单 | 首响是否 2h 内 |
| D11–D12 | 对 1 个 A 类询盘做寻源比价（3–5 家） | 比价表是否填满 |
| D13 | 出正式报价（18 字段 + 包含/不包含） | 有没有被自己漏掉的成本 |
| D14 | 复盘：这 3 个询盘哪一步最花时间 | 找到瓶颈 |

### 第 3 周：打样 + 下单（最危险的一段）

| 天 | 做什么 | 检查点 |
|---|---|---|
| D15 | 写打样规格书（含公差、色号、验收标准） | 工厂有没有回问"这里什么意思"（回问说明写清了） |
| D16–D19 | 打样；要求首件拍照确认后再做全套 | 首件照片到手 |
| D20 | 收样检验：量尺寸、对色卡、试功能、拍照 8 张 | 检验记录填了 |
| D21 | 客户签《样品确认书》→ 封样三份 → 拍照存档 | 三份封样贴标 |

### 第 4 周：跟单 + 验货 + 收尾

| 天 | 做什么 | 检查点 |
|---|---|---|
| D22 | 下 PO（六项齐全）+ 收定金 + 要水单 | 工厂盖章回传 |
| D23 | 建周报模板，发第 1 期 | 客户有没有回"收到" |
| D24–D26 | 每周固定发进度 + 车间照片 | 客户有没有主动催 |
| D27 | 约验货（出货前 5 天） | 验货员排期确认 |
| D28 | 验货 + 出报告 + 放行单 | 有 Major 缺陷吗 |
| D29 | 装柜监装（空柜/半装/满装/封条 4 张照）；核算客户实收/工厂实付/实际毛利三个数 | 误差 < 3% |
| D30 | 写复盘：3 条改进 + 更新 12 份模板 | 模板升版到 v1.1 |

## 六、每周固定检查点（4 个问题，每周五问自己）

1. 这周有几个询盘首响超过 2 小时？为什么？
2. 这周发出的报价单，有几份是手改的（没走成本表）？
3. 供应商库里，有几个 SKU 只有 1 家供应商？（这就是风险清单）
4. 这周有没有一件事，是"只有我能做"的？如果有 5 件以上，说明你还没开始减负。

---

## 七、第一个月允许不完美（现在不用管的三件事）

很多人 0→1 卡住，是因为想把 8 个节点全做成完美版，然后一个月过去一单没跑。

**这个月明确不用管：**

1. **不用建系统。** 共享表格够用。买 ERP/CRM 是第 20 单以后的事。
2. **不用做供应商分级打分。** 这个月只要"每个关键 SKU 有 2 家"，评分卡先放着，第 2 个月再用。
3. **不用做品牌、官网、宣传册。** 你的第一批客户来自你现有关系，不来自官网。

**这个月必须做到的三件事（只三件）：**
- 每一个询盘都有首响记录
- 每一份报价都出自同一张成本表
- 每一单都有封样和留样

---

## 八、第一个月的成功标准（不是赚钱）

| 指标 | 目标 | 为什么是它 |
|---|---|---|
| 询盘首响达标率 | ≥ 90% | 这是客户体验的第一道门 |
| 报价走成本表比例 | 100% | 口径统一的唯一证明 |
| 关键 SKU 双源覆盖 | ≥ 80% | 断供风险的底线 |
| 有封样+留样的单 | 100% | 责任可追溯的地基 |
| 8 节点留痕数 | ≥ 6 个 | 才算"跑通" |

**第一个月不设利润目标。** 第一个月设利润目标，会让你为了赚钱跳到不该接的单上，然后翻车。
