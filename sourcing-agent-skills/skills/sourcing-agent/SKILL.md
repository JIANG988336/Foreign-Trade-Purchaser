# Sourcing Agent · 外贸采购代理方法论

一套面向**采购代理（sourcing agent）**模式的完整工作方法：从询盘到交付的全链路流程、
可直接上墙的资产库、以及五个真实翻车场景的复盘。

本文件是索引与运行规则；详细内容在 `references/procurement-playbook.md`（约 2.4 万字）。

## 适用前提

使用者运营的是**采购代理模式**：受托于海外买家，代为寻源、比价议价、跟单验货；收入由
佣金（3%–8%）、服务费与产品差价构成；不持有货物所有权，但为交付结果背书。

原文由一位实际操盘的代理公司经营者（Feng）在转型期编写，目的是把"靠人、靠记忆、靠个人微信"
的流程，变成"可培训、可交接、可对客户展示"的系统。因此这套内容的特点是**偏执行、偏证据链、
偏风险兜底**，而不是偏理论。

## 结构性张力（整份文档的主线）

> 不拥有货物，却要为结果背书；赚的是差价，客户以为赚的是佣金。

所有客诉与信任危机的源头都在这里。所以文档里的每一条规则，最终都能归到三个目的：

1. 让客户理解**我为什么贵**（信任）
2. 出事时**我拿得出证据**（留痕）
3. 钱先到我方、质量我先扛（资金与责任结构）

## 何时使用本 Skill

- 要搭一套从询盘到交付的完整流程，且需要能直接培训新人
- 要统一报价口径，解决"同一产品不同人报不同价"
- 要建供应商准入、分级、评分与退出机制
- 要根治"样品合格、大货翻车"
- 要设计验货标准、客诉追溯与赔付口径
- 要向客户展示专业度（提案用的流程图与信任锚）
- 要做 0→1 的第一单

不适用：纯物流/报关/结汇/税务的实操，招聘与绩效考核制度设计。

## 八阶段主流程

```
① 询盘与需求确认  ② 寻源与比价  ③ 报价与议价  ④ 打样与封样
⑤ 下单与合同      ⑥ 跟单与变更  ⑦ 验货与出运  ⑧ 交付与客诉
```

四个断点，断一环就出事故：

| 断点 | 后果 | 对应动作 |
|---|---|---|
| ①→② | RFQ 规格书没写清，后面所有报价和打样都是废纸 | 规格书双签 + 版本号 |
| ②→④ | 没有客户书面确认的封样就下大货 | Golden Sample + 三份签封 |
| ④→⑤ | 定金未到账就下排产单 | 财务确认到账后才下 PO |
| ⑦→⑧ | 验货报告与装柜照片缺失，索赔无据 | 证据链归档 6 个月以上 |

## 运行规则（AI 使用本 Skill 时）

1. **先定位，再展开**。判断用户处在八阶段的哪一段，只展开相关章节，不要从头讲一遍全流程。
2. **数字不臆造**。税率、运费、认证费、AQL 抽样数，没有来源就标【需核实】。
3. **区分"可直接用"和"需按自身调整"**。文档中的毛利底线、准备金比例、金额门槛均为参考值，
   不同品类与规模差异很大，引用时要说明这一点。
4. **结论要有动作**。每条建议能回答：谁、什么时间、做什么、产出什么。
5. **守住边界**。出运与单证只涉风控决策（放货、电放），具体办单交单证/货代；
   报关、结汇、税务只提示接口与风险。
