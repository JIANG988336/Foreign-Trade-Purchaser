# Sourcing Agent Skills · 外贸采购代理 Skill 集

纯 Markdown 的提示词资产，把通用大模型变成一个有十余年经验的中国出口**采购总监**——找厂、报价、
议价、封样、跟单、验货，出事时能拿出证据的那个人。

没有代码，没有框架，只有结构化的作业知识。作者本人就在做采购代理。

---

## 这套东西想解决什么

国内的采购代理，绝大多数靠"隐性知识"在运转：供应商躺在某个业务员的微信里，报价从记忆里出来，
打样没有确认节点，老员工一走，公司就忘了怎么做事。

这些失误是可以预见的，代价也很具体：

- 同一款产品，两个业务员报出两个价，客户只会得出一个结论：这家公司要么不专业，要么在骗我。
- 样品过了，大货翻车，没人能证明当初批的是什么——因为没有封样、没有签字确认、没有留样。
- 新人三个月才能独立，因为没人写清楚每一步做什么、做完该留下什么东西。

这个仓库试图把这类知识，变成机器能执行、新人能照着做的东西。

## 三个 Skill

| Skill | 规模 | 是什么 |
|---|---|---|
| [`sourcing-agent`](skills/sourcing-agent/) | 约 2.4 万字（references） | 完整方法论：八阶段流程、14 节资产库、5 个实战案例 |
| [`sourcing-agent-lite`](skills/sourcing-agent-lite/) | 约 1500 字 | 可直接粘贴的人格提示词 |
| [`sourcing-zero-to-one`](skills/sourcing-zero-to-one/) | 约 2000 字 + 30 天计划 | 新公司第一个月的执行方案 |

三者不是三个工具，是同一套系统的三个视角：**母本**（它怎么运转）、**人格**（AI 怎么说话）、
**计划**（第一天做什么）。

## 几个值得说明的设计取舍

**1. 那套 17 模块的模板，是重构不是扩写。**

起点是一份常见的"提示词生成器"模板，17 个平铺模块——角色、背景、写作原则、风格语气、受众、
行业核心词、行业违禁词、热点信息、创始人 IP 等。那是从内容营销里长出来的结构。用于采购，
其中八个模块是空热量：供应商审核这件事里，没有"广告法违禁词"这个东西。

所以改成四层：**身份 → 判断 → 场景 → 资产**。字数全部压在资产层，因为那是唯一能执行的部分。

**2. 把"不确定"写进结构里，而不是指望它自觉。**

一个会编税率的采购顾问，比没有顾问更糟。所以人格里带三个机制：

- **追问协议**——信息不足时最多问 3 个问题，每个说明"为什么问"，并且必须同时给一版基于
  默认假设的答案。不许只用问题挡回来。
- **置信度分级**——每条结论标【可直接用】/【需核实】/【假设】。整篇都是【可直接用】的，视为偷懒。
- **禁语清单**——不许说"保证""100%""最低价"。对客户的绝对承诺，是代理公司给自己制造的
  无法兑现的责任。

**3. 结构性张力是整份文档的主线。**

采购代理不拥有货物，却要为结果背书；赚的是差价，而客户以为赚的是佣金。几乎所有的客诉和信任
危机，都能追回这个错位。所以每一条规则都要过一遍同一个问题：**这条是在缩小差距，还是在放大它？**

这也是为什么文档里有"打包价 / 成本+服务费"的双选项报价、四层信任诊断（真实性 → 能力 → 过程 →
利益），以及一条不留余地的规矩：**尾款不到账，不电放、不寄正本提单。**

**4. 拿另一份独立编写的 SOP 做了交叉比对。**

另有一份 15 环节的跟单 SOP，逐条比对后只合并增量：差价与佣金对照表、RFQ 六栏回价、供应商准入
红线、样品编号与寄样、DUPRO 中期验货、AQL 判定值、变更单纪律、采购合同十大条款、唛头核对、
电放风控，以及五个案例。已经覆盖的部分，不重复。

## 怎么用

**Claude Code / Claude Skills**：把某个 skill 文件夹放进 skills 目录，按名字调用。

**任意对话模型**：把 `skills/sourcing-agent-lite/SKILL.md` 去掉 YAML 头之后，作为系统提示
粘进去。要做深水区工作，再从 `procurement-playbook.md` 里取对应章节作为补充上下文。

**当纸质手册用**：`procurement-playbook.md` 是照着"能打印"写的。末尾那份 10 条上墙清单，
就是设计来贴在工位旁边的。

## 刻意不覆盖的部分

- 订舱、报关、结汇、税务——这些是交接出去的。唯一的例外是**放货决策**，因为差价模式下货权
  单据是唯一筹码，这个决定属于负责人，不属于单证员。
- 法律意见。合同十大条款是起草起点，不是法律建议。
- 招聘与薪酬制度设计。

## 关于文中数字

10% 毛利底线、3%–5% 售后准备金、30% 预付款上限、AQL 判定值等，都是**某一个经营者处境下的
参考值**。品类、订单规模、目的市场不同，差异很大。请当作校准起点，不要当标准照搬。

依赖实时数据的项目（关税、海运费、认证费）在文中一律标注需核实，没有给成事实。
